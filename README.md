# gonetmap

Сканер локальной сети с веб-интерфейсом. Периодически проверяет адреса в указанных IPv4-сетях. Живые хосты он сохраняет в базу SQLite вместе с именем (PTR), MAC-адресом и открытыми портами. Список хостов показывается в браузере.

## Возможности

- Сканирование одной или нескольких сетей CIDR (IPv4, от /16 и меньше)
- Два способа проверки: системный `ping` и TCP-подключение к заданным портам
- Определение имени хоста через обратный DNS
- Получение MAC-адресов из ARP-кэша ОС
- Хранение истории: когда хост впервые и в последний раз был в сети
- Автоудаление давно не появлявшихся хостов
- Веб-интерфейс и простой JSON API
- Без CGO: используется SQLite на чистом Go (`modernc.org/sqlite`)

## Требования

- Go 1.22+
- Команда `ping` в системе (для метода `ping`); root-права не нужны

## Сборка

Веб-интерфейс встраивается в бинарник из каталога `web/`, поэтому `index.html` должен лежать в `web/index.html`.

```bash
git clone <URL репозитория> gonetmap
cd gonetmap
go mod tidy
go build -o ipmanager .
```

Сборка под другую ОС, например Windows:

```bash
GOOS=windows GOARCH=amd64 go build -o ipmanager.exe .
```

## Запуск

1. Отредактируйте `config.yaml` и укажите свои сети в `scan.networks`.
2. Запустите:

   ```bash
   ./ipmanager                      # использует ./config.yaml
   ./ipmanager -config /path/to/config.yaml
   ```

3. Откройте в браузере http://127.0.0.1:8080.

Первое сканирование запускается сразу после старта, следующие — с интервалом `scan.interval`. Сканирование можно запустить вручную из веб-интерфейса. Для остановки нажмите `Ctrl+C` (или отправьте SIGTERM): программа дождётся завершения сканера и закроет базу.

## Конфигурация

Обязателен только параметр `scan.networks`, у остальных есть значения по умолчанию. Неизвестные ключи в YAML считаются ошибкой.

| Параметр | По умолчанию | Описание |
|---|---|---|
| `scan.networks` | — | Список сетей CIDR (только IPv4, не крупнее /16) |
| `scan.interval` | `5m` | Интервал между сканированиями (минимум `10s`) |
| `scan.timeout` | `1s` | Таймаут одной проверки хоста |
| `scan.concurrency` | `128` | Число одновременно проверяемых адресов (1–1024) |
| `scan.methods` | `[ping, tcp]` | Способы проверки: `ping`, `tcp` |
| `scan.tcp_ports` | `[22, 80, 443, 445, 3389]` | Порты для метода `tcp`; открытые сохраняются в базе |
| `scan.resolve_names` | `true` | Определять имена через обратный DNS |
| `scan.forget_after` | `0s` | Удалять хосты, не появлявшиеся дольше этого срока (`0` — хранить всегда) |
| `database.path` | `ipmanager.db` | Путь к файлу SQLite (создаётся автоматически) |
| `web.listen` | `127.0.0.1:8080` | Адрес веб-интерфейса |

Пример:

```yaml
scan:
  networks:
    - 192.168.1.0/24
    - 10.0.0.0/24
  interval: 5m
  methods: [ping, tcp]
  tcp_ports: [22, 80, 443]
  forget_after: 720h   # 30 дней

database:
  path: ./ipmanager.db

web:
  listen: 127.0.0.1:8080
```

> **Важно:** в приложении нет аутентификации. Если открыть доступ из сети (`listen: ":8080"`), любой, кто может подключиться к порту, увидит список хостов и сможет запускать сканирование. Используйте такой режим только в доверенной сети или за обратным прокси с авторизацией.

## API

| Метод | Путь | Описание |
|---|---|---|
| `GET` | `/api/hosts` | Список всех известных хостов |
| `GET` | `/api/status` | Состояние сканера: `running`, `last_scan`, `next_scan`, `networks` |
| `POST` | `/api/scan` | Запустить сканирование вне расписания (`202`; `409`, если уже идёт) |

```bash
curl http://127.0.0.1:8080/api/hosts
curl -X POST http://127.0.0.1:8080/api/scan
```

## Замечания

- MAC-адреса известны только для хостов из того же L2-сегмента. Для хостов за маршрутизатором поле останется пустым.
- Хост, ответивший на TCP-подключение отказом (`connection refused`), считается живым.
- Если команда `ping` не найдена, при старте выводится предупреждение, и работает только метод `tcp`.
